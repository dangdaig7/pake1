TROUBLESHOOTING:

  Q: "Python not found"
  A: Download from https://www.python.org/downloads/
     Check "Add Python to PATH" during install

  Q: ".bat file won't run"
  A: Right-click → Run as Administrator

  Q: ".exe won't start"
  A: Run as Administrator or disable antivirus temporarily

  Q: "ModuleNotFoundError: pytz"
  A: Type: pip install pytz
     Then run the build again
