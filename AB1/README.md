## 🚀 Quick Start

### **Option 1: Run as Python Script**

```bash
python AB1.py
```

Requirements:
- Python 3.6+
- Tkinter (included with Python)

### **Option 2: Build as Windows Executable**

1. **Double-click:** `BUILD_AB1.bat`
2. **Wait:** 1-2 minutes
3. **Find:** `dist\AB1.exe`
4. **Run:** Double-click `AB1.exe`

Requirements:
- Python 3.6+
- PyInstaller (installed automatically by script)

## 🔧 Troubleshooting

### "Python not found"
1. Download Python: https://www.python.org/downloads/
2. Check "Add Python to PATH" during installation
3. Restart your computer

### ".bat file won't run"
1. Right-click the .bat file
2. Select "Run as Administrator"
3. Allow when prompted

### ".exe won't start"
1. Right-click → Run as Administrator
2. Temporarily disable antivirus
3. Try again

### "Where is my data?"
1. Look for: `AB1_data.json`
2. Same folder as AB1.exe
3. Open with any text editor
